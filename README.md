# Service Request Portal

A mini project for **Essentials of Web Programming**, built with HTML, CSS and JavaScript.

## Features
- Form to raise a service request (name, email, phone, category, priority, description)
- Client-side form validation with error messages
- Requests saved in the browser (localStorage), so they stay after refresh
- Update the status of a request: Pending, In Progress or Resolved
- Filter requests by status, with live counts
- Delete requests
- Responsive layout

## Technologies
- HTML5
- CSS3 (Grid and Flexbox)
- JavaScript (DOM, events, localStorage)

## How to run
1. Download or clone this repository.
2. Open the folder in Visual Studio Code.
3. Right-click `index.html` and choose **Open with Live Server**, or just double-click `index.html` to open it in a browser.
